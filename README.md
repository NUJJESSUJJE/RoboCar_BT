Este proyecto consiste en crear un coche robot desde cero, montarlo y programarlo con Arduino, y controlarlo mediante Bluetooth desde una aplicación móvil hecha con App Inventor, tambien se ha creado una pagina web donde se explica en que consiste el proyecto y un enlace donde nos redirige al manual de instalacion y de programacion del coche y se ha creado una carcasa echa desde cero en tinkercad para que los componentes queden protegidos.
